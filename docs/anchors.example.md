# 锚点清单示例（docs/anchors.example.md）

把本文件复制为 `<工作区>/.dsh-meow/anchors.md` 即可使用。每行一条；`#` 开头为注释；行首 `- ` 可省。

挑选原则：**丢了就会让后续工作跑偏的前提**。状态类、进度类内容不要放进清单（那是交接文档的职责）。

```markdown
# 关键前提锚点清单
#
# 用法：每行一条关键前提短语；# 开头为注释；行首 "- " 可省。
# 插件在上下文压缩时检查：被压缩区间里出现过、但压缩摘要里消失的标注锚点，会优先报警。

## 世界硬事实
- 故事发生在落锁后第四年
- 无人值守机制没有观察者、答复、奖惩或援军

## 体系前提
- 力量必须有代价
- 初阶为形在身／我注道；中阶为形入世／我以道注世；高阶为形留世／道注我

## 协作纪律
- 一次推进一个完整模块
- 候选稿经审查与确认后才落档
```

操作方式：

- 手工编辑该文件（任何文本编辑器均可）；
- 让模型调用 `premise_anchor` 工具（list / add / remove）；
- 或使用 `/anchor add <短语>` 命令（操作默认清单）。
